# Abecedario Futbolero

Juego de ruletas para jugar entre amigos: se gira una ruleta de categorías y otra de letras, y cada jugador tiene que nombrar un futbolista que cumpla las dos. Cada futbolista elegido va a una posición del equipo de ese jugador (4-3-3, 4-4-2, etc.). Después de 11 rondas se comparan los equipos y se debate cuál quedó mejor.

Se publica automáticamente en GitHub Pages con cada push a `release`.
